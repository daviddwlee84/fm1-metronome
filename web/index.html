Editing here needs no FM-1. To read or send: METRONOME 0.3 or newer, a USB data cable, Chrome or Edge (allow MIDI with SysEx when asked), and no other program holding its MIDI port. Over Bluetooth: METRONOME 0.4 or newer.

The setlist (a white key each; ★ the song it starts on)

Song 1

120BPMALLEGRO 4/4 QUARTERS

A step: off → ghost → normal → accent (click it, as a white key on the FM-1). The height is how loud. In triplets the meter reads as 6/8, 9/8, 12/8 and the BPM is the dotted quarter's.

The rhythm-watch way: the quarter on the beat, the other layers between the beats, each at its own volume (K1–K4).

On the FM-1

SET is the stage page: pick songs, change the tempo. HOME goes one level down to the song's GRID (steps, beats, meter presets) or CLASSIC (four volumes, the accent). A setlist sent from here waits on the FM-1's screen: PLAY loads it, HOME keeps what is there. More in the cheatsheet.

The file

A plain JSON file ("app": "METRONOME", "kind": "setlist"): the stored songs by key, each with its tempo, sound, GRID steps (. g N A) and CLASSIC mix. The same file works with the command line (python -m fm1_metronome backup / restore). Plan on a phone, send from a computer.

METRONOME is free software (GPL-3.0-or-later), built on fm1-base. Not made by M-VAVE.
